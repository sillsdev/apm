# Multimodal oral and text pipelines

APM coordinates two parallel content pipelines that must not be conflated in product language or architecture.

**Oral pipeline:** vernacular and related audio artifacts → workflow steps (Record, PBT, etc.) → publishing to **Akuo** for listener consumption.

**Text pipeline:** transcriptions stored as metadata on audio files → Ready to Sync → **Paratext Sync** (cloud or desktop-local folder) for scripture text workflows.

Publishing means releasing oral content. **Paratext Sync** means transferring approved transcriptions. **Cloud Sync** means keeping project data consistent with the cloud API. These use different workflow steps, permissions, destinations, and state machines — and the word "sync" alone is ambiguous.
