# Vernacular versioning

Vernacular audio is the only artifact type with an independent version history per passage. Each save of a new vernacular recording increments the version; the latest version is **current** for workflow, Community Testing, Peer Review, and publishing decisions.

All other artifacts (PBT, WBT, careful speech recordings, etc.) link to the vernacular version they were created from. They do not carry their own version sequences — re-recording vernacular invalidates or forks the downstream artifact relationship through that version link.
