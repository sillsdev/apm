  Stored
  ||Place||What is saved||
  |Team default ({{{}organization.defaultParams{}}}, key {{{}asr{}}})|The resolved language, target, method, and transliterate flag. The team vernacular language is stored beside it under {{{}langProps{}}}.|
  |Workflow step tool settings|The step language, sister language, phonetic flag, transliterate flag, and method. A chosen method is the method name. Choosing Default stores {{{}default{}}}. A missing method means “use the team method.”|
  
  A choice made only for the current Run is not written back. The Save as team default button is what writes the team record.
  
  Resolved for a transcribe step
  
  {{getAsrSettings}} reads the current workflow step:
   * No step language: the team default.
   * Vernacular, Q&A, or Retell: the team default when the project language matches the team language and the step has no sister. Otherwise the project language, or the sister language when the service says the primary needs one. The step method wins when the step has an {{asrMethod}} key; otherwise the team method is kept.
   * Any other artifact: that step’s own language and sister, with only the method stored on the step.
  
  Used
   * Workflow step editor edits the step fields. For vernacular, Q&A, and Retell it also writes the resolved state back to the team default.
   * Desktop transcriber and mobile transcribe load that resolved state, show it in the language dialog, and send it on the transcription request. Default and phonetic requests omit the method.
   * Bold-clause transcription (including LWC) uses the upstream recording step. Vernacular recordings use the team resolution above. A named step language uses that language. A dialog choice for that step stays in memory while the editor is open and is not saved as the team default.
